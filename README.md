# Owners Plus Landing Page & Web Portal

> **Note**: Rebranded to **Owners Plus** to reflect the vision of owning your finances and making smarter financial decisions.

Official marketing landing page, privacy policy, and user data deletion portal for the **Owners Plus** mobile and web application.

- **Live Deployment**: [https://owners-plus-portfolio.vercel.app](https://owners-plus-portfolio.vercel.app)
- **Privacy Policy**: [https://owners-plus-portfolio.vercel.app/privacy](https://owners-plus-portfolio.vercel.app/privacy)
- **Data Deletion Request**: [https://owners-plus-portfolio.vercel.app/data-deletion](https://owners-plus-portfolio.vercel.app/data-deletion)
- **Account Deletion**: [https://owners-plus-portfolio.vercel.app/delete-account](https://owners-plus-portfolio.vercel.app/delete-account)

---

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site locally.

## Production Build

```bash
npm run build
```
